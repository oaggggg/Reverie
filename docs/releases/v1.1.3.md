# Reverie v1.1.3

## 体验焕新

- 统一桌面端按钮、弹窗、菜单和卡片的反馈节奏，保留“从哪来回哪去”的浮层动效。
- 增加键盘焦点提示，并支持 `Ctrl/Cmd + F` 搜索、`Ctrl/Cmd + ,` 打开设置。
- 页面滚动状态改为逐帧合并更新，降低快速滚动时的重复渲染。
- 窗口失焦或隐藏时暂停粒子封面与装饰动画，并降低播放进度刷新频率。

## Windows 与 macOS

- Windows 延续无边框标题栏与 NSIS 安装体验。
- macOS 改用原生交通灯、Overlay 标题栏和更贴近系统习惯的标题栏布局。
- macOS 提供 Universal 构建，同时支持 Intel 与 Apple 芯片。
- 发布流水线同时校验 Windows 与 macOS，并生成两个系统的安装产物。

## 安装说明

Windows 和 macOS 版本均不进行操作系统代码签名。Windows SmartScreen 或 macOS Gatekeeper 可能在首次运行时提示风险，请确认安装包来自本仓库的 GitHub Releases。

- Windows 安装包：`Reverie_1.1.3_Windows_x64_setup.exe`
- macOS 安装包：`Reverie_1.1.3_macOS_universal.dmg`

应用内更新仍使用 Tauri updater 完整性签名验证下载内容，该签名不属于 Windows Authenticode 或 Apple Developer ID 软件签名。
